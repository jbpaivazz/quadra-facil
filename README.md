# Quadra Fácil

Sistema de agendamento de quadras esportivas em Santa Inês e região.

## Objetivo

Facilitar a consulta de disponibilidade e a reserva de quadras, reduzindo conflitos de horários e organizando a gestão de reservas para usuários e administradores.

## Escopo inicial

- Consultar quadras e horários disponíveis.
- Selecionar um horário e solicitar uma reserva.
- Acompanhar os próprios agendamentos.
- Administrador cadastra quadras e gerencia reservas.

## Protótipo

A versão inicial é uma interface estática para validar o fluxo de consulta e reserva. Os dados são demonstrativos e ainda não são persistidos.

Abra `index.html` no navegador para visualizar.

## Estrutura

- `index.html`: estrutura da página.
- `src/styles.css`: estilos responsivos.
- `src/app.js`: interação de filtros e formulário de reserva.

## Próximos passos

1. Definir tecnologia de backend e banco de dados.
2. Implementar autenticação e perfis de usuário/administrador.
3. Persistir quadras, disponibilidade e reservas.
4. Validar regras de conflito no servidor.
